# Stock Market Trading Analysis Dashboard

## About the Project

I created this project to analyze stock trading data and understand trading performance, profit and loss, returns, and trade results.

I used **MySQL** to work with the trading data and **Tableau** to create the dashboard and visualize the results.

## Tools Used

* MySQL
* Tableau
* Excel

## Key Analysis

* Total Profit/Loss
* Total Trades
* Average Return
* Win Rate
* Average Profit per Trade
* Profit/Loss by Sector
* Profit/Loss by Stock
* Profit/Loss Trend
* Trade Result Distribution
* Average Return by Sector
* Trades by Sector

## Key Takeaways

The dataset contains **100 trading records**. The dashboard provides an overview of trading performance and allows comparison of profitability across sectors and stocks. It also shows return trends and the distribution of profit and loss trades.
